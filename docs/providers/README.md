# External Tool Providers

MIR delegates mature language tooling while retaining one configuration, reporting, and staged-index safety layer.

| Provider | Languages | Check | Fix | Format | Details |
| :--- | :--- | :---: | :---: | :---: | :---: |
| `ruff` | python | Yes | Yes | Yes | [Lint and format Python with Ruff.](ruff.md) |
| `eslint` | javascript, typescript | Yes | Yes | No | [Lint JavaScript and TypeScript with project-local ESLint.](eslint.md) |
| `prettier` | javascript, typescript, css, html | Yes | No | Yes | [Format JavaScript, TypeScript, styles, and HTML with Prettier.](prettier.md) |
